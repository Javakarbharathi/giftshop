# Fix Guide: Gift Shop Demo Issues

This file provides the exact steps to resolve the issues mentioned in `task.txt`, specifically the "Plain URL failure" and ensuring the backend connects correctly.

## 1. Fix: Website Not Loading (Plain URL vs Query Param)
The reported issue is that `https://giftshop-frontend-sigma.vercel.app/` fails, but adding `?utm_source=...` works. This is often caused by browser caching or service worker issues.

### Step-by-Step Fix & Confirmation:
1. **Incognito Test (Confirmation)**:
   - Open your browser in **Incognito/Private mode**.
   - Enter the plain URL: `https://giftshop-frontend-sigma.vercel.app/`
   - If it works here, the problem is your local browser cache.
2. **Hard Refresh**:
   - Open the site $\rightarrow$ Press `Ctrl + F5` (Windows) or `Cmd + Shift + R` (Mac).
3. **Clear Vercel Cache & Redeploy**:
   - Go to Vercel Dashboard $\rightarrow$ **Deployments**.
   - Click the three dots ($\dots$) on the latest deployment $\rightarrow$ **Redeploy** $\rightarrow$ Select **"Redeploy with clean build cache"**.

---

## 2. Fix: Backend Connectivity (Ngrok $\rightarrow$ Django)
Ensure the frontend can actually "talk" to your local laptop.

### Step-by-Step Execution:
1. **Start Backend (CMD 1)**:
   ```powershell
   cd C:\Users\javak\newproj\gem\gem\giftshop_backend
   .\venv\Scripts\activate
   python manage.py runserver 0.0.0.0:8000
   ```
2. **Start Tunnel (CMD 2)**:
   ```powershell
   ngrok http 8000
   ```
3. **Verify Tunnel URL**:
   - Copy the `Forwarding` URL (e.g., `https://xxxx-xxxx.ngrok-free.app`).
   - **Crucial**: Open this URL in your browser. If you see "Tunnel not found" or a 404, the backend isn't running. If you see a Django error or a blank page, the tunnel is working.
4. **Update Vercel Environment Variable**:
   - Go to Vercel $\rightarrow$ **Settings** $\rightarrow$ **Environment Variables**.
   - Edit `VITE_API_URL`.
   - Ensure it is exactly: `https://xxxx-xxxx.ngrok-free.app/api/` (Replace `xxxx` with your current ngrok URL. **Include the trailing slash**).
   - **Change Type to "Config"** (instead of Secret) if prompted, to ensure the Vite build includes it.
5. **Redeploy Frontend**:
   - Environment variable changes require a new build. Go to **Deployments** $\rightarrow$ **Redeploy**.
