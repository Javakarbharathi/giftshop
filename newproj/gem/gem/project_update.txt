1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
TN36 Custom Gifts is a full-stack, bilingual (English & தமிழ்) e-commerce and 
live-customization web platform designed for manufacturing and retailing 
personalized laser-crafted acrylic keepsakes, vehicle number plate tags, luxury 
wooden photo frames, resin floral coasters, and bulk wedding/event return gifts.

The platform provides a 100% interactive design studio where customers can upload 
photos, crop & zoom inside precision geometric silhouettes, select frame 
materials and sizes, engrave bilingual Tamil/English dedications, and preview 
high-resolution mockups before placing orders.

--------------------------------------------------------------------------------
2. TECHNOLOGY STACK ARCHITECTURE
--------------------------------------------------------------------------------

A. FRONTEND CLIENT (giftshop_frontend)
   • Core Architecture   : React 18 (Single Page Application) powered by Vite 8
   • UI & Design Tokens  : Custom Vanilla Tailwind CSS with a strict color system:
                           - Primary CTA    : Warm Artisan Terracotta (#EA580C)
                           - Secondary Bold : Obsidian Slate (#0F172A)
                           - Surfaces       : Porcelain Canvas (#FAFBFD) & White Cards
   • Bilingual Localization: i18next & react-i18next supporting instant switching
                           between English and Tamil across 100% of UI components.
   • Canvas Image Engine : react-easy-crop + HTML5 2D Canvas with normalized 
                           geometric bezier clipping algorithms (cropUtils.js).
   • Vector Masks        : Scalable SVG clipPath definitions (clipPathUnits:
                           objectBoundingBox) ensuring 1:1 pixel-perfect match 
                           between live CSS preview and exported canvas blob.
   • Routing & Navigation: React Router DOM v6 with automated ScrollToTop listener.
   • Global State Mgmt   : React Context API:
                           - AuthContext     : Session & multi-role permissions.
                           - CartContext     : Tiered bulk discounts & coupons.
                           - WishlistContext : Server-persisted saved items.
                           - ToastContext    : Tactile UI feedback toasts.
   • Icons & Typography  : Lucide-React + Google Fonts ('Outfit' & 'Plus Jakarta Sans').
   • PWA & Mobile UX     : Native App Bottom Nav Bar, Service Worker (sw.js),
                           Web App Manifest (manifest.json), 44px+ tap targets.

B. BACKEND API SERVER (giftshop_backend)
   • Framework           : Python 3.12 + Django 5.x + Django REST Framework (DRF)
   • Relational Database : MySQL Database (shop_db) with schema migrations.
   • Multi-Role Security : Role-Based Access Control (RBAC) with 4 distinct roles:
                           1. Customer        : Store browsing, studio, orders.
                           2. Admin           : Catalog CRUD, analytics, pricing.
                           3. Shop Owner      : Laser queue, photo blobs, UTR check.
                           4. Delivery Partner: Route dispatches & live checkpoints.
   • Payment Systems     :
                           1. Razorpay API Integration (Cards, Net Banking, UPI).
                           2. Dynamic UPI QR Scanner (GPay, PhonePe, Paytm, BHIM).
                           3. Cash on Delivery (COD) workflow.
   • Mail Automation     : Automated SMTP order receipts and dispatch notifications.
